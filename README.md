
# 🌟 Star AI: Your Personal AI WhatsApp Manager
> **Official Repository of Star AI — Built by Founder Shyam Kharte**


**Star** is a sophisticated, Generative AI-powered WhatsApp assistant designed to manage personal communications, provide smart responses, and alert the owner of important interactions. Built with a focus on security and efficiency.

---

## 🚀 Key Features
- **Smart Onboarding:** Greets users with a custom professional welcome message.
- **Real-time Admin Alerts:** Instantly notifies the owner with the sender's Name, Number, and Time.
- **Gemini AI Integration:** Powered by Google Gemini Pro for natural and intelligent conversations.
- **Security-First Design:** Implements secure environment variable handling to protect sensitive API keys.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Framework:** Flask (Webhook Management)
- **Messaging:** Twilio WhatsApp API
- **AI Brain:** Google Generative AI (Gemini Pro)
- **Environment:** Designed for VPS/Replit deployment

## 📋 How It Works
1. **Trigger:** User sends a "Hi" or "Hi Star" to the Twilio number.
2. **Response:** Star provides a professional welcome and asks for the message.
3. **Alert:** Star captures the message and forwards it to Shyam with full sender details.
4. **Completion:** Confirms the delivery to the user and waits for the next interaction.
